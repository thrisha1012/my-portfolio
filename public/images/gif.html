⚠️ 2. Image Warnings — Missing sizes Prop with fill

You are using:

jsx
<Image src={...} fill style={{ objectFit: "cover" }} />

But Next.js wants this to include a sizes prop to better manage responsive image behavior.

🔍 What sizes does:

sizes tells the browser how much screen width the image will take — this helps load the correct resolution, improving performance and Core Web Vitals.

✅ How to fix fill + sizes warnings:

Add a sizes prop like this:

jsx
<Image
  src={img01}
  alt="about-img-1"
  fill
  sizes="(max-width: 768px) 100vw, 50vw"
  style={{ objectFit: "cover", borderRadius: "5px" }}
/>

Explanation of sizes:

  • 100vw: full width on mobile

  • 50vw: half of the screen width on larger screens (like desktops)

You can tweak the values depending on how wide the image is displayed at each screen size.
